# Imagens dos exercícios

Guarde aqui as imagens permanentes dos exercícios.

Pasta recomendada: `assets/images/exercises/`

Use nomes simples, em minúsculas e sem acentos, por exemplo:

- `remada-baixa-no-cabo.webp`
- `supino-reto.webp`
- `agachamento-livre.webp`

Prefira WebP ou JPG quadrado, com pelo menos 300 × 300 px. Antes de publicar, confirme que você tem licença ou autorização para usar cada imagem.
